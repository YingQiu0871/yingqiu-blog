这篇文章本身就是文档——下面所有效果，任何文章都可以直接使用。

## 五个栏目

每篇文章归属五个稳定栏目之一。栏目是博客的长期结构，不随文章增多而膨胀；具体主题一律用**标签（tags）**表达。

| `category`  | 栏目 | 中文 URL         | 收录内容                 |
| ----------- | ---- | ---------------- | ------------------------ |
| `fuguang`   | 浮光 | `/fuguang/`     | 日常、旅行、心情与当下   |
| `jiujian`   | 旧笺 | `/jiujian/`     | 童年、小学到高中时期的旧文 |
| `liusheng`  | 流声 | `/liusheng/`    | 音乐、歌单与歌的记忆     |
| `qiushu`    | 求索 | `/qiushu/`      | 求学、科研与实验室       |
| `shiju`     | 拾句 | `/shiju/`       | 摘抄、诗词与阅读片段     |

英文路由与之对应（如 `/en/moments/`）。

## 文件放在哪里

文章是 `content/blog/` 下的 MDX 文件，每种语言一个文件：

```text
content/blog/
├── en/
│   ├── hello-yingqiu.mdx
│   └── writing-a-post.mdx
└── zh/
    ├── hello-yingqiu.mdx
    └── writing-a-post.mdx
```

文件名（去掉 `.mdx`）就是 slug，也就是网址：中文 `/posts/writing-a-post/`、英文 `/en/posts/writing-a-post/`。中英版本通过相同的文件名配对。

## Front matter

每个文件以 YAML front matter 开头：

```yaml
---
title: '文章标题'
description: '一句话摘要，会出现在列表、RSS 和搜索结果里。'
date: 2026-08-12            # 必填：整理/发布到这里的日期
updated: 2026-08-14         # 可选
category: fuguang           # 五个栏目 id 之一，缺省为 fuguang
tags: [指南, MDX]           # 主题标签，也支持逗号分隔的字符串
cover: /images/covers/x.jpg # 可选：卡片封面图
draft: true                 # 可选；为 true 时文章不出现在列表和 RSS 中
# —— 旧笺（jiujian）专用 ——
originalDate: 2019-06       # 原作时间：2019 / 2019-06 / 2019-06-15 均可
rereadNote: '多年后重读：……'   # 正文前的按语
# —— 拾句（shiju）专用 ——
quote: '句子原文'
quoteSource: '《书名》· 作者'
# —— 流声（liusheng）专用 ——
music:
  - title: 歌名
    artist: 歌手
    url: https://music.163.com/#/song?id=123   # 可选：外部链接
    note: 一句关于这首歌的记忆                    # 可选
---
```

| 字段            | 必填 | 用途                                       |
| --------------- | ---- | ------------------------------------------ |
| `title`         | 是   | 文章标题                                   |
| `description`   | 是   | 卡片、RSS 与元数据使用的摘要               |
| `date`          | 是   | `YYYY-MM-DD`，按时间倒序排列               |
| `updated`       | 否   | 有值时显示在日期旁边                       |
| `category`      | 否   | 栏目 id，缺省为 `fuguang`                  |
| `tags`          | 否   | 主题标签，数量与粒度不限                   |
| `cover`         | 否   | 卡片封面图路径                             |
| `draft`         | 否   | 设为 `true` 可暂时隐藏未完成的文章         |
| `originalDate`  | 否   | 旧笺专用：原作时间                         |
| `rereadNote`    | 否   | 旧笺专用：正文前的“多年后重读”按语         |
| `quote`         | 否   | 拾句专用：摘句原文                         |
| `quoteSource`   | 否   | 拾句专用：出处                             |
| `music`         | 否   | 流声专用：曲目列表，渲染成玻璃面板         |

旧笺按 `originalDate` 倒序排列（最近在前），其余栏目按 `date` 倒序。草稿不会出现在列表、RSS 和站点地图里，但可以用 `npm run dev` 在本地预览。

## Markdown 特性

- **加粗**、*斜体*、`行内代码`照常使用。
- 链接是普通的：[博客首页](/)。

### 代码块

带语言的围栏代码块会自动语法高亮：

```ts
export function getPosts(lang: string): BlogPost[] {
  return fs
    .readdirSync(path.join(BLOG_DIR, lang))
    .filter((file) => file.endsWith('.mdx'))
    .map((file) => readPost(lang, file.replace(/\.mdx$/, '')))
    .filter((post): post is BlogPost => post !== null && !post.draft)
    .sort((a, b) => b.date.localeCompare(a.date));
}
```

### 图片

图片放到 `public/images/` 下，用绝对路径引用：

```md
![图片说明](/images/example.png)
```

### 音乐嵌入

流声栏目可以在 MDX 里直接嵌入 Spotify / Apple Music / 网易云播放器：

```mdx
<Embed src="https://open.spotify.com/embed/track/4cOdK2wGLETKBW3PvgPWqT" height="152" />
```

## 双语文章

同时写 `content/blog/en/<slug>.mdx` 和 `content/blog/zh/<slug>.mdx`。如果缺少某种语言版本，读者会看到一个指向已有版本的友好提示面板。两版不要求同时发布——只有英文版时，中文路由上会显示回退面板。

## 发布

提交到 `main` 并推送。GitHub Actions 工作流会用 `NEXT_PUBLIC_SITE_URL` 构建站点、重新生成 RSS，并把 `out/` 同步到服务器的 `/var/www/blog`——完整流程见主仓库的 `deploy/DEPLOY.md`。
